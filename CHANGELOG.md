# Changelog

## 0.2.0 — 2026-09-14

- Раскладка управляющего компьютера при работе через Screen Sharing: переключение флага по Caps Lock и коррекция по набранным буквам.
- Автозапуск при входе в систему (пункт меню), установка в `/Applications` через `install.sh`.
- Код разделён на файлы; очередь требований `backlog/` и навыки цикла разработки.

## 0.1.0 — 2026-09-14

Первый прототип.
- Флаг раскладки над текстовым курсором; скрытие при наборе, повторный показ после настраиваемой паузы (мс).
- Поиск курсора: `AXBoundsForRange`, text marker (Chromium/WebKit), расчёт по ширине текста (омнибокс Chrome), запасные варианты у поля и у мыши.
- Проверено в Chrome, Telegram, VS Code, Obsidian, Word, Excel.
