# Очередь требований

Один файл на требование: `NNN-slug.md`. Просмотр: `python3 scripts/backlog.py` (см. `--help`).

## Формат

```markdown
---
id: 012
title: Короткое название
status: new
priority: medium
group: remote
size: M
created: 2026-09-14
updated: 2026-09-14
---

## Запрос
Что хочет пользователь и зачем — его словами, с примерами.

## Анализ
Причина / суть, варианты с рекомендацией, риски, зависимости.

## План
Шаги реализации и сценарий проверки для пользователя.

## Итог
Что сделано, в какой версии, что осталось.
```

## Поля

- **status:** `new` (записано) → `analyzed` (есть анализ и план) → `in-progress` → `testing` (ждёт проверки пользователем) → `done`; также `deferred` (отложено) и `rejected` (отказ с причиной в «Итоге»).
- **priority:** `high` | `medium` | `low`.
- **group:** тема для пакетной разработки: `positioning`, `remote`, `appearance`, `settings`, `performance`, `tooling`, `layout`.
- **size:** оценка объёма `S` (до часа) | `M` (сессия) | `L` (несколько сессий); `?` — пока не оценено.
