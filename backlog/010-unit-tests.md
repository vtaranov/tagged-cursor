## Запрос
Сейчас автоматических тестов нет: всё проверяется вручную (пользователь смотрит на флаг, Claude читает лог). Нужны автоматические тесты, чтобы изменения по очереди шли под защитой от регрессий и `/develop` мог отсеивать поломки до установки версии.

Покрыть логику, не зависящую от чужих приложений:
- распознавание раскладки: письменность символов (`script(of:)`), соответствие раскладок флагам;
- удалённый режим как конечный автомат: пара событий Caps Lock, долгое нажатие (см. #003), коррекция по набранным буквам, сброс при локальной смене раскладки;
- геометрия: перевод координат AX → Cocoa, `collapsed()`, отбраковка «рамки поля» Excel, положение флага (над курсором; под ним у верхнего края экрана);
- логика показа/скрытия: пауза повторного показа, клавиши навигации, Cmd/Ctrl.

## Анализ
Предварительно (проверено 2026-10-22):

- Swift Testing работает без Xcode, только с Command Line Tools. Проверено на пробном пакете: тест проходит при двух условиях — в `Package.swift` указать `platforms: [.macOS(.v13)]` (иначе макрос `@Test` раскрывается в код, требующий macOS 10.15+, и сборка падает) и передать пути к фреймворкам:
  ```
  F=/Library/Developer/CommandLineTools/Library/Developer/Frameworks
  L=/Library/Developer/CommandLineTools/Library/Developer/usr/lib
  swift test -Xswiftc -F -Xswiftc $F -Xlinker -F -Xlinker $F \
             -Xlinker -rpath -Xlinker $F -Xlinker -rpath -Xlinker $L
  ```
  Обернуть в `test.sh`.
- Требуется рефакторинг: вынести логику из `Controller` в тестируемые типы без обращений к AX/TIS/NSEvent. Ориентир — состояние раскладки (локальная/удалённая, события как структуры данных) и решение «показывать/скрывать» как чистая функция от состояния и времени. Системные вызовы остаются тонким слоем в `Controller`.
- Сборка приложения остаётся на `swiftc` (`build.sh`); пакет SwiftPM — только для тестов, с теми же файлами `Sources/` в качестве цели. Проверить, что `@MainActor`-типы и AppKit не мешают сборке тестовой цели; при необходимости выделить логику в отдельную папку/цель.
- Риск: рефакторинг затрагивает `Controller` целиком — после него обязательна полная ручная проверка по `docs/test-matrix.md`.
