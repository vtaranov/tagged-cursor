# Обзор очереди

1. `python3 scripts/backlog.py list` (или с фильтрами, если пользователь просит: `--status`, `--group`, `--priority`, `--all`).
2. Покажи таблицу пользователю.
3. Если есть `in-progress` или `testing` — напомни о них первыми: незакрытая работа важнее новой.
4. Предложи следующий шаг — одну рекомендацию, не перечень:
   - `new` с высоким приоритетом → `/analyze`;
   - `analyzed` требования одной группы с малым размером → разработать пакетом через `/develop`;
   - требования, зависящие друг от друга, — вместе.
5. Если пользователь просит подробности — `python3 scripts/backlog.py show <id…>` и краткий пересказ.
