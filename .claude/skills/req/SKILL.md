# Занести требование в очередь

1. Сформулируй требование(я) из обсуждения. Несколько независимых пожеланий — несколько требований.
2. Проверь дубли: `python3 scripts/backlog.py list --all` и при необходимости `show <id>`. Если это уточнение существующего открытого требования — дополни его раздел «Запрос» (с датой) вместо нового файла.
3. Для нового: номер из `python3 scripts/backlog.py next-id`, файл `backlog/NNN-slug.md` по формату из `backlog/README.md`.
   - `status: new`, `size: ?`, `created`/`updated` — сегодня.
   - «Запрос» — суть словами пользователя, конкретные примеры, приложения, режим (локально / Screen Sharing), скриншоты описать текстом.
   - Если по ходу обсуждения уже понятны причина или вариант решения — запиши их в «Анализ» пометкой «предварительно», статус оставь `new`.
   - `priority` и `group` — предложи сам; уточняй у пользователя только приоритет, если он неочевиден.
4. Уточняющие вопросы — только если без ответа требование нельзя сформулировать проверяемо.
5. Покажи строку(и) очереди: `python3 scripts/backlog.py list`.
6. Закоммить: `git add backlog && git commit -m "backlog: #NNN <название>"`.

Ничего не реализовывать в рамках этого навыка.
