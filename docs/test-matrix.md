# Матрица ручной проверки

Режимы: **L** — клавиатура MacBook, **R** — Screen Sharing с Mac Studio. Отмечать при изменениях, затрагивающих соответствующую часть.

| Сценарий | Ожидание | Режим |
|---|---|---|
| Смена раскладки при пустом поле | флаг сменился сразу | L: системный переключатель, R: Caps Lock |
| Набор текста | флаг исчезает с первой клавиши, появляется через паузу | L, R |
| Набор в «другой» раскладке после переподключения | флаг исправляется после первой буквы | R |
| Переключение окон / приложений | флаг появляется у курсора нового окна | L, R |
| Claude desktop / Obsidian / Telegram | флаг над курсором | L |
| Chrome: поле на странице | над курсором | L |
| Chrome: омнибокс, короткий и длинный текст | над курсором, погрешность ~1%, у правого края при прокрутке | L |
| VS Code: обычная строка, горизонтальная прокрутка | над курсором | L |
| VS Code: курсор ушёл за пределы видимой области | флаг скрыт | L |
| Word: обычный режим | над курсором | L |
| Word: Outline | у указателя мыши | L |
| Excel: строка формул, редактирование ячейки | у начала поля; Excel не падает | L |
| Поле пароля | флаг не показывается | L |
| Заметки / Mail (AppKit) | флаг вплотную над строкой, не на строку выше | L |
| Меню: пауза, автозапуск, версия | значения сохраняются | L |
