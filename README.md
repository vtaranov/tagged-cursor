# Tagged Cursor

Флаг текущей раскладки (🇷🇺/🇺🇸) над текстовым курсором в macOS. Флаг появляется при смене окна, поля ввода или раскладки, после клика и после паузы в наборе. Исчезает при нажатии клавиши, чтобы не мешать печатать.

Иконка в меню-баре: пауза перед повторным показом, автозапуск, строка диагностики: приложение · тип поля · способ, которым найден курсор.

## Чего ожидать

В macOS нет системного способа узнать, где на экране текстовый курсор. Каждое приложение рисует его само и сообщает его координаты через Универсальный доступ (Accessibility) по-своему: одно точно, другое с ошибкой, третье вообще не сообщает. Tagged Cursor перебирает несколько способов и подстраивается под конкретные приложения, но угадывает не везде.

Где проверено и работает: Chrome и другие Chromium-браузеры, Telegram, Заметки, Mail, Obsidian, Claude, VS Code, Word. С оговорками:

- **Омнибокс Chrome:** позиция рассчитывается по ширине текста, на длинной строке погрешность около 1%.
- **Excel:** флаг стоит у начала поля, а не у курсора.
- **Word, режим структуры:** координат нет, флаг показывается у указателя мыши.
- **VS Code:** нужны `"editor.accessibilitySupport": "off"` и `"editor.editContext": false` в настройках, иначе позиция неверная.

Если приложение не отдаёт позицию курсора, флаг ставится у начала поля или у мыши. Сообщения о таких приложениях полезны: иногда для них удаётся найти свой способ.

## Установка

Нужны macOS 13+ и Command Line Tools. Xcode не нужен.

```bash
xcode-select --install          # если ещё не установлены
git clone https://github.com/vtaranov/tagged-cursor.git
cd tagged-cursor
scripts/make-cert.sh            # один раз: сертификат подписи в связке «Вход»
./install.sh                    # сборка, установка в /Applications, запуск
```

При первом запуске macOS попросит разрешить Универсальный доступ: «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ», включить Tagged Cursor. Приложение само добавится в автозапуск, отключить можно в меню.

Сертификат нужен, чтобы разрешение не сбрасывалось при каждом обновлении: macOS привязывает его к подписи. Он самоподписанный, действует только на вашем маке и не даёт приложению никаких прав. При первой сборке macOS может спросить доступ `codesign` к ключу — разрешите («Разрешать всегда»).

Обновление:

```bash
git pull && ./install.sh
```

Удаление: выйти из приложения через меню, удалить `/Applications/TaggedCursor.app`, убрать его из «Универсального доступа». Сертификат «Tagged Cursor Dev» удаляется в «Связке ключей».

## Приватность

Приложение читает через Универсальный доступ положение курсора и тип поля ввода, а также следит за нажатиями клавиш, чтобы прятать флаг при наборе. Набранный текст и нажатые клавиши никуда не записываются и не отправляются, сетевых запросов нет. Поля паролей пропускаются.

## Сообщить о проблеме

[Issues](https://github.com/vtaranov/tagged-cursor/issues): версия (в меню), версия macOS, приложение, где флаг стоит неверно, и строка диагностики из меню, снятая, когда курсор в этом поле. Скриншот очень помогает.

Лог для диагностики (без набранного текста):

```bash
/usr/bin/log show --last 10m --predicate 'subsystem == "local.tagged-cursor"' --style compact
```
